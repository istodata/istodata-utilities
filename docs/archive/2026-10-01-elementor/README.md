# Historical Elementor prototypes and acceptance evidence

Archived on 2026-10-02 from the September 30 / October 1 investigation.
`docs/` and `tests/` retain the original grouping and file contents.
`manifest.json` records every original path, archived path and SHA256.
Two shared parser helpers are copied here while remaining in active `tests/`.

These are historical snapshots, not current deployment tools. Scripts may
depend on retired staging probes, private sessions, dated server paths or old
runtime assumptions. Do not run or install them as the current acceptance suite.
Historical reports and patches describe their own builds and policies.

Current guidance remains in `docs/elementor-fragment-cache.md` and
`docs/elementor-compatibility.md` at the repository root. Final access/preview
acceptance and the subsequent wording deployment remain in the root `docs/`.
See root `tests/README.md` for maintained checks.

Generated Python bytecode, the empty probe packaging directory and the
superseded probe ZIP were removed from the workspace into a recoverable TEMP
folder after automatic approval rejected deletion. `generated-cleanup.json`
records their destinations. Their source prototypes are preserved here.
Runtime plugin files and site state are outside this cleanup.
